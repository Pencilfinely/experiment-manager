# Experiment Manager 0.4.5

本版本将移动监控页面和授权接口加入正式管理端安装包。手机端依赖管理端后台服务；管理端停止后，手机不能同步状态或提交操作。

## 更新与接入

1. 在电脑管理端主动检查更新到 **0.4.5**，或下载本页的 `ExperimentManager-0.4.5-windows-controller-x64-Setup.exe` 手动更新，沿用原来的数据目录。
2. 更新完成后，刷新管理页面，进入 **设置 → 移动端访问**，为手机创建独立的只读或有限操作凭证。
3. 手机与管理电脑接入互通的局域网或可信私网。在手机应用中填写 `http://管理电脑私网IP:端口`，使用私网 HTTP 时勾选允许选项，再输入移动凭证。
4. 也可直接通过手机浏览器访问 `http://管理电脑私网IP:端口/mobile/`。

默认服务为 HTTP，通常使用 8765 端口；未配置 TLS 时不要改为 HTTPS，否则会出现 SSL 协议错误。以实际配置的地址和端口为准，手机上的 localhost 指向手机自身。跨不可信网络使用有效 HTTPS 或可信私网。

## 移动功能

- 查看实验概况、搜索与筛选、指标及曲线、累计时长、最新日志、参数、结果文件清单和节点资源。
- 有限操作包括停止 / 取消实验、支持续训时恢复，以及暂停 / 恢复节点接单；不支持手机创建实验、导入算法或完整结果下载。
- 设备凭证支持只读 / 有限操作权限、有效期及撤销。管理员和算力节点凭证不能用于手机登录，服务端只保存移动凭证的哈希。
- 前台定时同步；数据过期或断网时禁用操作。命令版本检查阻止旧页面重复提交，网络恢复不会自动重发命令。

## Android 与 HarmonyOS 6

- 发布附件 `ExperimentMonitor-0.1.0-debug.apk` 为 **Android 测试包**，最低 Android 9。已通过 Kotlin 编译、Android Lint 和 APK 签名校验，尚未完成 Android 真机验收。
- Mate 70 Pro / HarmonyOS 6 可尝试通过卓易通安装 APK；是否支持该包需实测，尚未验证兼容工具中的运行效果。[华为官方安装说明](https://consumer.huawei.com/cn/support/content/zh-cn16061787/)
- 仓库提供以 API 20 为目标的原生 HarmonyOS 工程，**尚未完成 ArkTS 编译、签名 HAP 和鸿蒙真机验收**。本次不提供 HAP 安装包。
- Android 客户端不包含实验数据或预置凭证，首次使用必须连接管理端并输入单独签发的移动凭证。

## 验证

移动接口覆盖角色隔离、只读限制、过期撤销、命令冲突和发布资源；共用界面已完成手机宽度浏览器验证。测试和构建结果不能替代实际手机及网络环境验收。

更新由用户手动发起，不自动修改防火墙、开放公网访问、启用显卡或签发手机凭证。详细步骤见仓库 `mobile/README.md`。
